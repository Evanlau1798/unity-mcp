# Unity-MCP Tools Reference

Choose the relevant category below; do not load every reference by default. The installed MCP schema is authoritative for availability and parameters. The examples in these references are templates, not verified project results.

Tools outside `core` may be hidden. Where supported, use `manage_tools(action="list_groups")` and activate only the needed group. For response envelopes and resource URIs, use the [resource index](resources-reference.md).
